Overview

A fullstack web application for purchasing concert tickets online. Built with Laravel for backend ticket quota management and React for a responsive, interactive seat selection and checkout experience with real-time availability feedback.

Features

  • Browse concerts with event details, artist info, and venue maps
  • Ticket category selection (Regular, VIP, VVIP) with live quota display
  • Shopping cart with multi-ticket support and quantity validation
  • Secure checkout flow with order summary and confirmation
  • Admin dashboard for event and ticket quota management
  • Responsive UI optimized for both desktop and mobile

Implementation

Laravel handles all business logic server-side: quota validation on ticket reservation, order creation, and admin CRUD for events. React manages the UI state — cart, ticket counts, real-time availability updates — via local state and context API.

  • Laravel REST API with request validation and resource transformers
  • React Context API for global cart state management
  • MySQL schema: events → ticket_categories → orders → order_items
  • Atomic ticket reservation to prevent overselling
  • Tailwind CSS for consistent, mobile-first responsive design

Key Challenges

The main challenge was preventing race conditions in ticket reservation — two users buying the last ticket simultaneously. Solved with database-level transactions and row locking in Laravel's Eloquent, ensuring atomic decrement of available quota.
