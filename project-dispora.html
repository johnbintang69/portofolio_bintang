Overview

An internship project to rebrand and modernize the official website of Dinas Kepemudaan dan Olahraga (Dispora) Kota Semarang — the city's youth and sports agency. The goal was to replace an outdated, slow portal with a modern, accessible, and content-managed web platform.

Problem

The existing Dispora website suffered from an outdated design, slow page loads, and no content management workflow. Staff had no easy way to update news, events, or program information without direct database access.

  • No CMS — content updates required manual DB edits
  • Poor mobile responsiveness
  • Outdated visual identity inconsistent with Semarang city branding
  • No structured API layer for future integrations

Solution

Built a fullstack platform with Laravel as the API backend and React as the interactive frontend, decoupled via RESTful endpoints. A custom admin panel allows staff to manage news, programs, and events without touching the codebase.

  • Laravel REST API with sanctum-based auth for admin panel
  • React frontend with Tailwind CSS for responsive, modern UI
  • MySQL relational database with structured content schemas
  • Role-based admin access for content management
  • Performance optimization: lazy loading, image compression, CDN assets

Results

Delivered a fully functional, rebranded government web portal with a clean content management workflow. The site launched as an improved digital touchpoint for Semarang's youth and sports community.
