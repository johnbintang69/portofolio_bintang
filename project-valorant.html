Project Overview

This study aims to deliver an objective prediction of team victory at the VALORANT Champions Tour (VCT) 2025. Given that esports performance analysis often falls into subjective bias, this project applies Delta Analysis to measure performance gaps between teams objectively through discriminative feature extraction.

Algorithms Tested

The project compares five Machine Learning algorithms to find the best prediction model:

  • Naïve Bayes
  • Decision Tree
  • XGBoost
  • CatBoost
  • Stacking Classifier

Results & Conclusion

Model evaluation was conducted comprehensively using a dataset of 1,507 observations from VCT 2025 matches.

  • Stacking Classifier — 75.72% (most optimal)
  • XGBoost — 75.19%
  • Naïve Bayes — 74.26%
  • CatBoost — 73.59%
  • Decision Tree — 72.86%

The synergy of meta-learning combined with Delta Analysis proved capable of producing more stable analytical generalization in handling the complexity of modern esports data.
